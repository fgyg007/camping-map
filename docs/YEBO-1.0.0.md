# 野泊 1.0.0

基于通过试用的 0.3.2：记录营地和到访实测；在概览写私人点评；按需分享地点及车辆实测。

## 从测试版迁移

1. 在测试版点「导出备份」，把完整 JSON 保存在应用之外，保留测试版。
2. 安装正式版「野泊」。它与两个旧测试包使用不同包名，可以并装。
3. 先在正式版点「恢复我的备份」，如需车辆资料，勾选「同时恢复备份中的车辆资料」，确认个人点评、照片、实测及车辆信息，再导入车友分享。旧版在数据核对前不要卸载。

正式版固定应用 ID `com.jlmac.yebo`，后续保持同一长期签名并递增 Android 版本号。GitHub 仓库是私有的，Release 下载页仅对有仓库访问权限的人可用；可单独分享签名后的 APK，不需要公开源码。
