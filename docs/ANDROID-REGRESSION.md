## 以后每个候选 APK 都按下列场景验收

每轮记录被测 commit、APK SHA-256、实际包名、证书 SHA-256、版本号、Android 版本和第三方地图版本。注明「单测」「浏览器模拟」「模拟器安装」「真机」，不要互相替代；未覆盖或失败写清影响。以合成地点、图片和车辆进行测试，不把个人地点带进测试包或日志。

| 场景 | 验收要求 |
| --- | --- |
| 首页、地点、收藏 | 新装离线有列表，不请求地图瓦片；新增或编辑后回首页，收藏状态不丢；完全退出并冷启动，再按名称和坐标复核。 |
| 百度保存点 | 同一 WGS-84 点，已装百度 App 时直接拉起并落在正确标记；没装或不能拉起时用相同点开网页，并明确提示。没有在打开地图时附带地点名或备注。 |
| 高德和 Google | 高德已装/未装两条路径对照同点；Google 测 HTTPS 链接在已安装和未安装时由系统选择的实际表现。避免把系统默认行为记成强制拉起。 |
| 链接导入 | 高德、百度、腾讯、Google 分别测试可解析的长链和短链：粘贴自动填写链接可证实的名称和坐标，确认后只点一次保存。百度页面中心可作为近似候选，写明来源并可打开原链接比较；仅返回 UID 而无法展开时不猜坐标。更换链接不保留前一次自动填写的旧值，不能覆盖未保存的手填坐标。测试系统分享的冷启动与后台已有实例。 |
| 车型 | 先选品牌再选同品牌车型；核对指定年款的尺寸，修改默认值后关掉并重开；切换品牌不能保留旧车型为新品牌的预设，手填车型正常保存，备份后恢复仍按手动值。车辆尺寸不是装载后的实测车高。 |
| 照片 | Android 系统相册选择一张与多张，压缩后可点开放大；持久化并彻底重启；删除一张后剩余照片不丢；损坏或不支持的文件有提示。不能只以浏览器选择合成 PNG 成功代替。 |
| 备份 | Android 分享面板打开不等于文件已安全保存；实际保存到可访问文件夹，再用独立安装/用户数据导入，核对坐标、照片、车辆、重启后的数据和重复导入。记录是合并导入而不是覆盖。备份包含用户资料，仅分享给预期对象。 |
| Android 系统备份 | 应用没有自动上传服务不等于系统备份被关闭。当前已交付包的 `allowBackup` 为 true；是否备份特定 WebView 数据仍未真机确认。 |
| 更新 | 只把包名一致、签名符合预期、versionCode 递增且已在填充数据的设备上完成覆盖安装并复核的版本标为可升级。旧调试包签名不匹配时，不以卸载/清除数据作为通过条件。 |

没有旧签名时，不能把现有同包名旧版升级成不同签名的新包。下一步应由所有者选择长期保管的签名和首个发布包标识；若旧签名最终不可恢复，保留旧版并测试一次用不同包名并装、导出/导入、核对数据的迁移。迁移以后固定包名与签名并递增版本号。仓库、调试产物和日志只保存公有证书指纹，不能保存私钥。
