## 高德短链接与 Android 系统分享

- 三个真实公共地点样本都经高德 302 到 wb.amap.com：两个 q=纬度、经度、名称；另一个 p=POI ID、纬度、经度、名称、地址。p/q 同时出现时拒绝导入；只用于核实格式，源码和测试不含地点、分享令牌或链接原文。
- 仅 Android 对精确高德 HTTPS 短链向高德 GET 一次，不读正文、不跟跳转、不存链接。严格校验跳转主机、路径与明确坐标，不猜地址。预览声明按高德 GCJ-02 约定换算，wb 链接不是公开稳定接口，尚未独立核对真实原图钉与换算精度。
- Android text/plain ACTION_SEND 进入待预览提醒；用户打开预览后自动读取并填入表单，不覆盖正在编辑的地点，不自动保存。微信内部分享并非系统分享，无法由本 App 截获；手填只保留作通用录入，不作为微信一键导入替代。
- 待真机：高德分享菜单是否出现野泊；冷启动与热启动接收；无名长按图钉/具名点的坐标比对；取消、重复分享、离线和过期链接。自动测试为合成样本。

### 百度地点分享实测（2026-11-18）
- 用户样本实测跳转返回 HTTP 302，百度地图详情地址只包含地点编号（UID），没有经纬度；真实链接和 UID 不写入仓库。
- 粘贴 Markdown 形式的分享链接时，去掉链接包装；地点编号类链接明确提示没有坐标，保留「打开原地图链接」，不填写或保存猜测坐标。回归测试只用合成样本。

### 百度桌面 POI 候选点

- 支持格式：百度地图 HTTPS 桌面 POI 长链接具有独立地点路径、明确的投影 X/Y/缩放级别以及单一 UID。也接受复制的 Markdown 同址链接及查询分隔符转义。参照[百度官方投影文档](https://lbsyun.baidu.com/docs/jsapi?title=jsapi4%2Fguide%2Fconcept%2Fprojection)离线反算百度经纬度，再用已有规则转换至 WGS-84；不是 EPSG:3857，求得的是画面中心候选点，不是对 UID 图钉定位。
- 粘贴后自动预览；已有表单坐标不动。打开原图或候选标点都需用户点击，只在「确认使用候选点」后填写表单，仍需另行保存；改变链接、放弃或关闭时清除候选。仅在编辑窗口保留原链接，不写入地点或备份。没有运行 UID 查询，也不发起打开地图以外的候选计算网络请求。
- Android 百度短链若直接返回受支持桌面地址，仅把跳转地址交给相同候选流程，不下载目标页面；仅返回 UID 的短链仍不能生成候选。没有加入 API Key 或后端。
- 回归使用百度文档的天安门公开投影示例与合成标识，覆盖 Markdown 查询格式、恶意/歧义输入和候选确认。浏览器用合成数据检查未确认不填、可保留原坐标、换链接和重开清除预览、确认后仍不自动保存。未用实机核对实际图钉或停车入口。

### Android 百度地点短链跳转差异（2026-11-19）

- 同一用户样本实测：桌面浏览器标识得到根路径的地点编号；Android Dalvik 标识得到 `/mobile/webapp/search/search/qt=inf&uid=…/…`，两种响应都是 HTTP 302，均未自带坐标。旧 Java 路由拒绝移动路径；新路由按严格的 HTTPS 主机、路径、唯一编号规则将其转成现有的公开桌面入口，不访问移动页面，不保留跟踪参数。
- 对实际返回分别运行旧、新 Java 路由以验证拒绝与同编号标准化；仓库测试只用合成编号。覆盖旧款移动地点详情路径、冲突编号、伪造主机和意外参数；不把地图画面中心当成地点标记。Android 从粘贴、页面加载到自动填入表单仍须独立实测。
